    14. Apêndices

    A instalação do [Android Studio], do emulador e a configuração de um celular são descritas no capítulo “Configuração do ambiente de desenvolvimento”. Estes apêndices complementam esse capítulo.

    14.1. Usando o Android Studio

    • [File / Open]: abre um projeto ([examples_kotlin], [rdvmedecins_kotlin]); o [Gradle] o “sincroniza” (baixa as bibliotecas);
    • o botão [Run] (ou Shift-F10) instala e inicia o aplicativo no dispositivo selecionado na barra de ferramentas; [Debug] (Shift-F9) o inicia com o depurador (pontos de interrupção, variáveis);
    • [Apply Changes] substitui o código de um aplicativo em execução sem reiniciá-lo, quando possível;
    • a anotação [@Preview] em uma função [@Composable] sem parâmetros a exibe no editor, sem um emulador;
    • o “Layout Inspector” ([Tools / Layout Inspector]) exibe a árvore de componentes da tela atual e o número de recomposições de cada componente; o “App Inspection” exibe as requisições de rede ([OkHttp]) e os bancos de dados;
    • Pressionar Alt-Enter em um erro sugere correções (adicionar um [import]...); Ctrl-Alt-L reformata o arquivo;
    • Linha de comando: [adb devices] (dispositivos conectados), [adb reverse tcp:8080 tcp:8080] (a porta 8080 do dispositivo conectada à porta do computador), [adb install file.apk] (instala um aplicativo), [adb logcat] (o log do celular; no [Android Studio], a janela [Logcat]), [emulator -list-avds] e depois [emulator -avd Pixel_8] (inicia um emulador sem o [Android Studio]).

    14.2. Capturas de tela deste documento

    As capturas de tela foram geradas automaticamente por testes INSTRUMENTADOS: testes [JUnit] que são executados NO emulador — no mesmo processo do aplicativo — e o controlam por meio da biblioteca de testes do [Compose] (encontrar um componente pelo seu texto, tocar nele, digitar nele etc.). O servidor JSON deve estar iniciado, com [CAPTCHA_TEST=test].

    14.3. Instalação do Node.js

    O [Node.js] pode ser baixado em nodejs.org: selecione a versão LTS (suporte de longo prazo). O instalador do [Windows] também instala o [npm]. Ele só é necessário para o servidor JSON. Verifique a instalação em um console:

    1
2
    node --version
npm --version

    14.4. Instalação do MySQL com o Laragon

    O servidor JSON requer o [MySQL] (ou o [MariaDB]). O [Laragon] (laragon.org) instala uma instância pronta para uso no [Windows] com a ferramenta de administração [HeidiSQL]. Após a instalação:

    • o botão “Start All” inicia o servidor [MySQL] na porta 3306;
    • o usuário [root] não tem senha: esses são os valores padrão do arquivo [.env.example] do servidor;
    • no [HeidiSQL] (botão “Database”), o item de menu File / Run SQL executa o script [database/dbrdvmedecins2.sql].

    Para [Linux] ou [macOS], instale o [MySQL] ou o [MariaDB] usando o gerenciador de pacotes do sistema e execute o script com o cliente de linha de comando: [mysql -u root -p < database/dbrdvmedecins2.sql].

    14.5. Instalação do curl

    [curl] já vem incluído no [Windows] versões 10 e 11, no [macOS] e na maioria das distribuições do [Linux]. Verifique sua versão:

    1
    curl --version

    A opção [--json], usada neste documento, está disponível desde a versão 7.82 (2022). Se você estiver usando uma versão mais antiga, substitua [--json @file] por [-H "Content-Type: application/json" -d @file], ou instale uma versão recente a partir de curl.se.

    No [PowerShell], é preciso digitar [curl.exe], e não [curl]: no [PowerShell], [curl] é um alias para outro comando ([Invoke-WebRequest]), que não inclui as opções do [curl]. O prompt de comando ([cmd]) não tem esse problema.
